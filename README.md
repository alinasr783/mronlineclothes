# MAISON ROYALE — Online Store

متجر أونلاين فاخر لبراند **Maison Royale** للهوديز — موقع ثابت (HTML / CSS / JavaScript) من غير أي build أو سيرفر، شغّال على GitHub Pages مباشرة.

## المميزات
- هوية كاملة من اللوجو: أسود ملكي + عاجي، خطوط Serif فخمة، نجمة اللوجو في كل التفاصيل.
- **Mobile-first**: شريط تنقّل سفلي زي التطبيقات، شنطة على شكل Bottom Sheet تتسحب لتحت، جاليري بالسحب، زرار "أضف للشنطة" ثابت تحت، مقاسات لمس كبيرة، دعم الـ notch / safe-area.
- **عربي / English** بزرار واحد مع RTL كامل.
- أنيميشنز: شاشة تحميل بتكشف اللوجو، ستارة بين الصفحات، هودي ثلاثي الأبعاد بيتحرك مع الماوس / ميلان الموبايل وبيغيّر لونه، غبار ذهبي، نصوص بتطلع حرف حرف، لوك بوك أفقي مع السكرول، أزرار مغناطيسية، كيرسر مخصص، المنتج بيطير للشنطة، انفجار نجوم عند الطلب.
- سلة، مفضلة، بحث فوري (عربي وإنجليزي)، أكواد خصم، شحن مجاني فوق حد معيّن.
- **الطلب بيتبعت على واتساب** برسالة جاهزة فيها كل تفاصيل الأوردر (الدفع عند الاستلام / إنستاباي).
- PWA: يتضاف للشاشة الرئيسية في الموبايل كأنه تطبيق.

## ⚠️ أول حاجة لازم تعملها
افتح `js/config.js` وغيّر:
```js
whatsapp: "201000000000",   // ← رقم الواتساب اللي هيستقبل الطلبات (بصيغة دولية من غير +)
instagram: "...", tiktok: "...", facebook: "...",
shippingFee: 85, freeShippingOver: 3500,
promoCodes: { ROYALE10: 10, WELCOME: 15 },
```

## تعديل المنتجات
كل المنتجات في `js/products.js` — الاسم، السعر، الألوان، الوصف بالعربي والإنجليزي.

الموقع حالياً بيرسم الهوديز كرسومات SVG فخمة بكل الألوان. لما تصوّر منتجاتك الحقيقية حط الصور في `assets/img/products/` وضيف للمنتج:
```js
images: {
  noir:  ["assets/img/products/monogramme-noir-front.jpg", "assets/img/products/monogramme-noir-back.jpg", "assets/img/products/monogramme-noir-detail.jpg"],
  ivory: ["...front", "...back", "...detail"]
}
```
والصور هتحل محل الرسومات أوتوماتيك.

## التشغيل محلياً
أي static server، مثلاً:
```bash
npx serve .
```

## النشر
الموقع منشور على GitHub Pages من فرع `main`.
